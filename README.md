# Telegram AI Bot

Простой Telegram-бот на Python.

## Возможности

- Команда `/start`
- Ответ на обычные текстовые сообщения
- Возможность подключения ИИ и генерации изображений

## Запуск локально

1. Установи Python 3.10 или новее.
2. Установи зависимости:

   ```bash
   pip install -r requirements.txt
